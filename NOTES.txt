1. API VERSIONING
-----------------------------------------------------------
Spring Boot 3 (Traditional Approaches - 4)
    - Path Versioning -> @GetMapping("/v1/test")
    - Request Parameter Versioning -> @GetMapping(value = "/test", params = "version=v1")
    - Header Versioning -> @GetMapping(value = "/test", headers = "API-Version=v1")
    - MIME/Content Negotiation Versioning -> @GetMapping(value = "/test", produces = "application/vnd.com.anshuit.rekroot.v1+json")

Spring Boot 4 (New API Versioning Support Approaches - 4)
    - Controller (same for all approaches except path):
        @GetMapping(value = "/test", version = "v1")
        @GetMapping(value = "/test", version = "v2")

    - Only the configuration changes.
        - Path Versioning → configurer.usePathSegment(index) → GET /api/v1/test
        - Request Parameter Versioning → configurer.useQueryParam("version") → GET /api/test?version=v1
        - Header Versioning → configurer.useRequestHeader("API-Version") → GET /api/test + API-Version: v1
        - MIME/Content Negotiation Versioning → configurer.useMediaTypeParameter(mediaType, "v") → GET /api/test + Accept: application/vnd.com.anshuit.rekroot+json;v=1

2. H2 DB
-----------------------------------------------------------
Add below dependencies : 
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-data-jpa</artifactId>
        </dependency>
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-h2console</artifactId>
        </dependency>
        <dependency>
            <groupId>com.h2database</groupId>
            <artifactId>h2</artifactId>
            <scope>runtime</scope>
        </dependency>

Define below properties :
    spring.datasource.url=jdbc:h2:mem:rekroot
    spring.datasource.driver-class-name=org.h2.Driver
    spring.datasource.username=sa
    spring.datasource.password=

    #H2 DB CONFIGS
    spring.h2.console.enabled=true
    spring.h2.console.path=/h2-console
    spring.sql.init.mode=embedded
    spring.sql.init.schema-locations=classpath:schema.sql
    spring.sql.init.data-locations=classpath:data.sql

5. Setting Up Docker Compose Feature
-----------------------------------------------------------
Problem without Docker Compose ?
    - When an application requires multiple containers (Spring Boot, MySQL, Redis, Kafka, etc.), you must start and configure each container separately using multiple docker run commands, making setup difficult and error-prone.

How Docker Compose solves it ?
    - Docker Compose allows you to define all containers, networks, ports, volumes, and environment variables in a single docker-compose.yml file and start the entire application stack with one command.

How to setup?
    Add below dependencies :
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-docker-compose</artifactId>
                <scope>runtime</scope>
                <optional>true</optional>
            </dependency>

    Add properties :
        # Docker(Docker Compose)
        spring.docker.compose.file=docker-compose.yml
        spring.docker.compose.lifecycle-management=start-and-stop
        spring.docker.compose.start.command=up
        spring.docker.compose.stop.command=down

7. Setting Up JPA Auditing Feature
-----------------------------------------------------------
- Create a BASE entity class and mark the BASE entity class with @MappedSuperClass annotation. Also, annotate the fields accordingly with multiple annotations.
- You need to annotate this BASE class with @Entitylisteners(AuditingEntityListener.Class) to tell jpa to start listening to this audit events like createdDate etc.
- Extend the BASE entity class created in above steps in all concrete class ( actual entity classes )
- To populate createdBy and updatedBy column , you need to implement your "auditoraware" by implementing AuditAware(I).
- Finally annotate your application with @EnableJpaAuditing(auditorAwareRef = "auditorAware") , and also tell which auditoraware impl to use.
